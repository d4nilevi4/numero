# Número

Минималистичные карточки для испанских чисел от **0 до 999 999 999 999**.

[Открыть тренажёр](https://d4nilevi4.github.io/numero/) · [GitHub](https://github.com/d4nilevi4/numero)

## Локальный запуск

Node.js 20+. Зависимостей нет, `npm install` не требуется.

```sh
npm run dev
```

Открыть http://127.0.0.1:4173. Остановить сервер — `Ctrl+C`.

## Использование

- Назови число и нажми «Показать ответ» или на карточку.
- На карточке появятся написание по-испански и транскрипция IPA. Русская подсказка включается отдельно.
- Та же кнопка станет «Следующее» — она даёт новую карточку и снова становится «Показать ответ». Нажатие на карточку работает так же.
- Можно отметить несколько диапазонов. В случайном режиме каждый выбранный диапазон имеет одинаковый шанс, поэтому миллиарды не вытесняют небольшие числа. Повторы возможны.
- По возрастанию числа проходят через объединение выбранных диапазонов, пропускают промежутки и после последнего возвращаются к первому. Пересечения диапазонов не дублируются.
- «Свой» добавляет произвольный диапазон к остальным. Ввод применяется кнопкой `OK`.
- Пробел выполняет текущее действие кнопки, стрелка вправо — следующая карточка. При вводе и работе с настройками сохраняется обычное поведение клавиш.

Сохраняются только настройки в браузере. Озвучки, микрофона, самооценки, счётчиков и истории нет.

IPA — широкая учебная запись по словам для уругвайского произношения с seseo и sheísmo: `millón` → /miˈʃon/, `millones` → /miˈʃones/. Русская подсказка: «мишо́н», «мишо́нес». В Уругвае встречается также звонкий вариант [ʒ], близкий к «ж»; для тренировки здесь выбран вариант [ʃ], близкий к «ш». Вокальные /j/ в дифтонгах и союз `y` /i/ от этого не меняются. Запись не передаёт все позиционные изменения звуков в слитной речи; русская подсказка приблизительна.

Написание сверено с [таблицей и правилами числительных RAE](https://www.rae.es/dpd/cardinales), включая `cien`/`ciento`, `veintiún mil`, `un millón` и `mil millones`. Испанское `mil millones` означает миллиард; `billón` — миллион миллионов, за пределами поддерживаемого диапазона ([FundéuRAE](https://www.fundeu.es/consulta/mil-millones-millardos/)).

Источники о произношении: [Instituto Cervantes — Montevideo](https://cvc.cervantes.es/LENGUA/voces_hispanicas/uruguay/montevideo.htm) и Michnowicz & Planchón, [Sheísmo in Montevideo Spanish](https://doi.org/10.1075/ihll.29.07mic), 2020. Общие принципы IPA, дифтонгов и ударения: Martínez-Celdrán, Fernández-Planas & Carrera-Sabaté, [Illustrations of the IPA: Castilian Spanish](https://doi.org/10.1017/S0025100303001373), 2003.

## Проверка и сборка

```sh
npm test
npm run build
npm run preview
```

Сборка создаёт статический сайт в `dist/`. CSS и весь граф JS-модулей получают общий хеш версии в URL, чтобы браузер после обновления не подхватывал старую таблицу произношения из кэша. Относительные пути подходят для GitHub Pages, включая размещение в подпапке репозитория. Workflow `.github/workflows/pages.yml` запускает тесты, сборку и публикацию в Pages при push в `main`. В Settings → Pages выбран источник GitHub Actions. Workflow также можно запустить вручную.
